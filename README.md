# Proste przetwarzanie obrazów w Python

## Co robi program
- wczytuje obraz z internetu
- zmniejsza go
- konwertuje do czarno-białego
- obraca o 90 stopni
- wyświetla wynik

## Jak uruchomić
do uruchomienia należy zainstalować bibliotekę:
pip install opencv-python matplotlib numpy

Uruchom:
python main.py
